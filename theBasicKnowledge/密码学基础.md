## 1、异或运算： 
加密就是将明文和密钥对应的 ASCII 码转换成二进制后进行**按位异或**
 异或：相同为0，不同为1
 数学特性：
- **归零律**：`A ^ A = 0`（任何数与自身异或，结果必为 0）
    
- **恒等律**：`A ^ 0 = A`（任何数与 0 异或，保留原值不变）
    
- **交换律**：`A ^ B = B ^ A`
    
- **结合律**：`(A ^ B) ^ C = A ^ (B ^ C)`
    
- **可逆性（自反性）**：如果 `A ^ B = C`，那么 `C ^ B = A` 且 `C ^ A = B`
## 2、流密码：
 核心是异或运算
 - 注意两条明文不要用同一密钥加密
 - 如果使用相同的 Key 和 Nonce 加密了两个不同的明文 $P_1$ 和 $P_2$，就会产生相同的密钥流 $K$：

$$C_1 = P_1 \oplus K$$

$$C_2 = P_2 \oplus K$$

攻击者将两个密文直接异或，就能消去密钥流：

$$C_1 \oplus C_2 = (P_1 \oplus K) \oplus (P_2 \oplus K) = P_1 \oplus P_2$$

由此，攻击者可以通过统计分析或已知部分明文直接推导出剩余的明文内容。
**常见流密码算法**：RC4、Salsa20、ChaCha20

## 对称加密（加解密钥相同）
- DES：
![[Pasted image 20260730185151.png]]
**1**、初始置换（IP置换）：将输入的64位明文块进行置换和重新排列，生成新的64位数据块。

**2**、加密轮次：DES加密算法共有16个轮次，每个轮次都包括四个步骤：

    a. 将64位数据块分为左右两个32位块。

    b. 右侧32位块作为输入，经过扩展、异或、置换等操作生成一个48位的数据块。这个48位的数据块被称为“轮密钥”，它是根据加密算法的主密钥生成的子密钥。

    c. 将左侧32位块和轮密钥进行异或运算，结果作为新的右侧32位块。

    d. 将右侧32位块与原来的左侧32位块进行连接，生成一个新的64位数据块，作为下一轮的输入。

**3**、 末置换（FP置换）：在最后一个轮次完成后，将经过加密的数据块进行置换和重新排列，得到加密后的64位密文。

- AES：
![[Pasted image 20260730200114.png]]
**1**、字节代换：S盒：通过行和列查找对应的字节
**2**、列移位（密钥长度为128比特）：
    第0行不移位
    第1行向左移1位
    第2行向左移2位
    第3行向左移3位
**3**、列混合
列混合后的矩阵左乘一个固定的矩阵**加法是按位异或（$\oplus$），乘法是 $\text{GF}(2^8)$ 上的有限域乘法**
计算矩阵中的乘法时，只需掌握三个系数的加乘规则：

1. **乘以 $01$：** 保持不变。
    
2. **乘以 $02$（在 GF(2⁸) 中称为 `xtime`）：**
    
    - 将该字节左移 1 位。
        
    - 如果移位前的最高位（MSB）为 `1`，则移位结果要与 `0x1B`（即二进制 `00011011`）进行按位异或 $\oplus$。
        
3. **乘以 $03$：** 利用分配律转化为 $03 \cdot x = (02 \cdot x) \oplus (01 \cdot x) = \text{xtime}(x) \oplus x$。

- RC4
明文☞与密钥异或☞密文
**密钥的生成**：
- 1、初始化状态向量S（共256个字节，用来作为密钥流生成的种子1）
- 2、初始密钥（由用户输入），长度任意
    - 若输入的长度小于256个字节，则进行轮转，直到填满 就得到256个字节的向量T（用来作为密钥流生成的种子2）
- 3、开始对状态向量S进行置换操作（用来打乱初始种子1）
  按照以下规则进行：
~~~c
  j = 0;
  for (i = 0;i < 256;i++) {
     j = (j + S[i] + T[i]) mod 256;
     swap(S[i],T[i]);
  }
~~~
   **密钥是几字节就模几**
- 4、秘钥流的生成与加密
~~~c
假设我的明文字节数是datalength=1024个字节（当然可以是任意个字节）

i=0;

j=0;

while(datalength--){//相当于执行1024次，这样生成的秘钥流也是1024个字节

　　　i = (i + 1) mod 256;

　　　　j = (j + S[i]) mod 256;

　　　　swap(S[i] , S[j]);

　　　　t = (S[i] + S[j]) mod 256;

　　　　k = S[t]; //这里的K就是当前生成的一个秘钥流中的一位
~~~
- 最后用生成好的密钥逐bit与明文异或，得到密文



## 非对称加密
- RSA
   公钥加密，私钥解密。 
   公钥：$(E,N)$
   私钥：$(D,N)$
   其中E和N可以公开，D不可以公开
   加密：
$$密文=明文^EmodN$$
   解密：
   $$明文=密文^DmodN$$
  - 生成密钥对：
   $N = p * q$ （p和q是两个互质数，数的大小要足够大）
   中间量：$L = lcm (p - 1, q - 1)$ （L是p-1和q-1的最小公倍数）
   E：$1 < E < L，gcd（E，L）=1$（E，L最大公约数为1（==E和L互质==）
   D：$1 < D < L，e\cdot d \equiv 1 \pmod{L}$（条件2是为了保证密文解密后的数据就是明文）
   
## 二、 常见密码学场景中的“小”标准

在不同的密码学攻击场景下，“小”的具体界限有所不同：

| **场景 / 攻击类型**                              | **未知数的相对范围上界**                    | **实际数值参考示例**                               | **为什么这叫“小”？**                                      |
| ------------------------------------------ | --------------------------------- | ------------------------------------------ | -------------------------------------------------- |
| **多元线性方程（如本题）**                            | 未知数比特数之和 $< \text{bits}(p)$       | $p$ 为 512-bit，未知数分别为 160-bit、96-bit、64-bit | 空间中只有唯一一个极短向量满足约束，LLL 能 100% 捕获。                   |
| **RSA 小私钥攻击 (Wiener / Boneh-Durfee)**      | $d < N^{0.292}$                   | $N$ 为 2048-bit，私钥 $d < 2^{598}$            | $d$ 看起来有将近 600 位（很大），但相对于 2048 位的 $N$，它依然属于“小”的范畴。 |
| **RSA 高位/低位泄露 (Coppersmith 攻击)**           | 未知部分 $x < N^{1/e}$                | 当 $e=3$ 时，未知部分 $< N^{0.333}$               | 2048 位 $N$ 的情况下，只要泄漏了前 1360 位，剩下的 688 位未知数就可以直接解出。 |
| **背包密码系统 / 隐含数问题 (Hidden Number Problem)** | 未知数 $\approx 2^{32} \sim 2^{256}$ | 视格的维度（通常 $10 \sim 100$ 维）而定                | 维度越高，LLL 能容忍的未知数比例越低（维度太高会面临“维数灾难”）。               |
